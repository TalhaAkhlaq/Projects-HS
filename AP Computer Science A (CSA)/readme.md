# AP Computer Science A (CSA)

Java coursework and projects completed for AP Computer Science A.

## Course Overview
- Primitive types, expressions, casting, and operator precedence
- Objects and classes: fields, constructors, methods, scope, and encapsulation
- Control flow: boolean logic, conditionals, and iteration (for/while)
- Data structures: arrays, ArrayList, and 2D arrays (traversal patterns)
- Class design: composition, inheritance basics, and method overriding
- Problem solving: decomposition, testing, and edge-case handling

## Repository Contents
- `Airplane/` - small Java project
- `Calculating_Grades.java` - grade calculation logic and conditionals
- `ControlTower.java` - control-flow focused program
- `Sleep.java` - time or schedule calculation exercise
- `TimeConversion.java` - unit conversion and arithmetic practice
